# Coding standards

The standards this project holds its code to. The code reviewer reads this file on every review, alongside the kit's house standards, which hold in every project and are not repeated here.

Each rule here is a judgement call no check can make. Anything mechanical belongs in the project's linters, type checker or CI instead. `/devkit:retro` adds a rule when a judgement call keeps coming up; write each one as the rule, then why it holds.
